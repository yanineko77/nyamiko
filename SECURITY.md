# Nyamiko: безопасность

## Что где хранится

- Ключи подписки — только на телевизоре: `/media/internal/tv-tunnel/config.json`,
  права `600`. В репозиторий и в панель они не попадают.
- Панель показывает подписки как «сохранена / не задана», сами ссылки никогда
  не отдаёт обратно.
- В системный раздел телевизора ничего не пишется: клиент живёт в
  `/media/internal`, хуки автозапуска — в `/var/lib/webosbrew/init.d`.

## Панель открыта в локальной сети

По умолчанию панель доступна любому устройству в домашней сети **без пароля** —
это сделано, чтобы включать туннель с телефона. Панель умеет менять подписки,
поэтому:

- если в сети есть чужие устройства, поставьте в `config.json`
  `"require_key": true` — тогда обращения не с localhost потребуют
  `?k=<ключ>` (ключ сгенерируется и будет лежать в том же файле);
- никогда не выставляйте порт 8099 наружу (проброс на роутере) — панель не
  рассчитана на интернет.

## Что клиент делает с сетью

- Меняет маршрут по умолчанию на TUN-интерфейс и держит физический маршрут
  резервом; адрес VPN-сервера пиннится, чтобы туннель не зациклился.
- Если туннель перестал работать, сторож возвращает обычный интернет — телевизор
  не остаётся без сети.
- DNS уходит через туннель (DoH) при поднятом туннеле; локальные адреса и
  VK-домены идут мимо туннеля.

## Сообщения о проблемах

Нашли уязвимость — откройте issue без публикации деталей эксплуатации, либо
напишите приватно. Пожалуйста, не прикладывайте к issue свои ключи подписки,
логи с адресами серверов и MAC-адреса устройств.
