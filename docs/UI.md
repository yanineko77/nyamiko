# Панель: дизайн и поведение

## Принцип

Панель выглядит как системное меню телевизора, а не как веб-приложение:
чёрно-белая, тонкие рамки, подписи капсом, разделители вместо карточек, никаких
акцентных цветов, кроме смысловых (зелёная точка «подключено», красная —
ошибка). Выделение делается инверсией, поэтому интерфейс читается и с трёх
метров, и в тёмной комнате.

## Переменные темы

```css
:root[data-theme="light"]{--bg:#f1f1f1;--panel:#fff;--ink:#111;--line:#111;--sep:#d9d9d9;--ok:#1ec15f;--bad:#d63b3b}
:root[data-theme="dark"] {--bg:#0e0e0e;--panel:#161616;--ink:#f4f4f4;--line:#8f8f8f;--sep:#333;--ok:#39d97a;--bad:#ff6b6b}
```

Тема выбирается по `prefers-color-scheme` устройства. Если телевизор сменил тему
на ходу, а браузер не прислал событие, панель догоняет состояние опросом раз в
две секунды. Ручной выбор (`◐`: Авто → Тёмная → Светлая) сохраняется в
`localStorage`.

## Раскладки

| Ширина | Что происходит |
|---|---|
| ≥ 1500 px | полный заголовок, две колонки |
| 1150–1500 px | подпись под названием скрывается |
| ≤ 1150 px | одна колонка, страница прокручивается |
| ≤ 700 px | компактные отступы, кнопки в одну строку, узкие полоски задержки |

Отдельная проверка: 1920×1080 (телевизор) — панель обязана влезать без
прокрутки, иначе пультом неудобно.

## Анимации

| Элемент | Что происходит | Длительность |
|---|---|---|
| плитка | смена фона, подъём на 1 px, рамка фокуса | 140–160 мс |
| полоска задержки | плавный рост до нового значения | 550 мс |
| строка узла | появление снизу | 180 мс |
| точка состояния | мягкая пульсация при подключении | 2.4 с цикл |
| прогресс замера | бегущая штриховка | 1.1 с цикл |
| оверлей | проявление + подъём листа | 160–200 мс |

Всё выключается при `prefers-reduced-motion: reduce`.

## Управление с пульта

Стрелки двигают фокус по геометрии (ближайший элемент в нужную сторону, с
приоритетом вертикали), OK нажимает, BACK/Esc закрывает верхнее окно. Фокус
всегда видим жирной рамкой; если фокус ушёл за экран, строка подтягивается
плавной прокруткой. При открытии панели фокус ставится в первый элемент, чтобы
пульт работал сразу.

## Языки

Четыре полных набора строк (`I18N.ru/en/uk/be`) плюс «Авто (как в системе)».
Язык по умолчанию — язык телевизора; событие `languagechange` переключает панель
на ходу. Даты форматируются локалью языка (`toLocaleString`).
