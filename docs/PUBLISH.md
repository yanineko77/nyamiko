# Чек-лист выпуска

Рабочая копия проекта — `/root/nyamiko`; это дерево целиком уходит в репозиторий.

1. **Версия** — поднять в трёх местах: `CHANGELOG.md`, футер панели
   (`src/ui.html`, строка `Nyamiko vX.Y.Z`) и шапка `src/tvtunnd.js`.
2. **Секреты** — `grep -rInE 'https?://[^ ]+/sub/' .` должен давать только
   плейсхолдеры (`ваша-панель/sub/КЛЮЧ`, `your-panel/sub/KEY`); ключей, HWID,
   MAC, личных IP и IP телевизора в репозитории быть не должно.
3. **Синтаксис** — `sh -n` по всем скриптам (`install.sh`, `src/tunnelctl.sh`,
   `hooks/*`, `tools/*`), `node --check src/tvtunnd.js`, `python3 -m py_compile
   src/genconfig.py src/yamlite.py` и отдельно JS, вынутый из `src/ui.html`
   (то же делает CI).
4. **Проверка на живом телевизоре.** Пройдено на 0.4.0 (LG 2018, webOS 4.4):
   панель открывается и из сети, узлы видны (94), замер всех узлов идёт,
   переключение узла из панели работает, после перезагрузки телевизора панель,
   сторож и туннель поднимаются сами, `install.sh --update` из репозитория
   проходит все шаги и оставляет ключи и настройки на месте. Повторять при
   каждом релизе: панель → узлы → замер → переключение → перезагрузка ТВ →
   обновление из репозитория.
5. **Скриншоты** — снимаются из `src/ui.html` в браузере с `?demo=1`
   (демо-данные, 6 узлов). Состав `screenshots/`: `nyamiko-bw-light.png` и
   `nyamiko-bw-dark.png`, `ui-ru-dark.png`, `ui-en-light.png` — 1920×1080;
   `ui-laptop-uk.png` — 1440×900; `ui-phone-be.png` — 390×844. Тема и язык
   выставляются до загрузки страницы: `localStorage['nyamiko.theme']`
   (`light`/`dark`) и `localStorage['nyamiko.lang']` (`ru`/`en`/`uk`/`be`).
6. **Тег и релиз** — `sh tools/release.sh` собирает `nyamiko-<версия>.tar.gz`
   (файлы перечислены в скрипте, ключи и `config.json` в архив не попадают),
   затем `git tag vX.Y.Z && git push --tags` и релиз с этим архивом + changelog.
7. **Анонсы** — по возрастанию риска: GitHub → webosbrew-сообщество → 4PDA →
   Habr (технический пост) → англоязычные площадки. Рекламные формулировки про
   «обход блокировок» не использовать: это уже не код, а популяризация.
8. **Проверка установки с нуля** — прогнать `install.sh` на телевизоре, где
   клиента раньше не было (или после `rm -rf /media/internal/tv-tunnel`).
