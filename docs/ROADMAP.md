распространять. Порядок — по полезности, а не по красоте.

## 1. Надёжность и проверка (сначала это)

- [x] **Проверка на живом телевизоре (0.4.0).** Панель открывается и из сети,
      94 узла видны, замер всех узлов идёт, переключение из панели работает,
      после перезагрузки ТВ панель, сторож и туннель поднимаются сами,
      `install.sh --update` из репозитория проходит целиком. Это условие для
      анонсов выполнено — дальше можно показывать проект людям.
- [x] **Тесты парсера подписок** (`tests/run_tests.py`) — 46 проверок: URI-список,
      base64, Clash YAML (плоский и блочный), якоря, транспорты, сборка конфига,
      режимы, пустая и мусорная подписка. Запускаются в CI.
- [ ] **`shellcheck` и линтер JS в CI** — синтаксис ловит опечатки, но не
      неверные кавычки и мёртвые ветки.
- [x] **Транспорты**: `http`/`h2`, `httpupgrade`, `quic` теперь собираются в
      конфиг (раньше такие узлы выпадали из подписки). `xhttp` sing-box не
      поддерживает — по схеме ядра есть только http, ws, quic, grpc,
      httpupgrade, — поэтому такие узлы отбрасываются, но панель показывает,
      сколько и почему.
- [ ] **Экспорт диагностики одной кнопкой** в панели: состояние, маршруты,
      версии ядра, хвост логов — одним файлом, чтобы человек мог приложить его
      к сообщению об ошибке, не заходя по ssh.
- [ ] **Обновление клиента из панели** (кнопка «обновить»): скачать файлы
      релиза с GitHub и перезапуститься — сейчас для этого нужен ssh и
      `install.sh --update`.

## 2. Распространение

- [~] **`.ipk` для Homebrew Channel** — главный канал: установка с пульта, без
      ssh. Собрано: `packaging/ipk` (структура приложения, сборка через
      `ares-package`, манифест с `rootRequired`, вызовы root через
      `hbchannel.service/exec|spawn`, открытие панели в браузере телевизора).
      Проверено на живом ТВ: пакет собирается и содержит верную структуру,
      ставится через `com.webos.appInstallService/dev/install`, появляется в
      списке приложений и запускается (виден на экране); root-сервис Homebrew
      Channel отдаёт команды от `uid=0` любому вызывающему, включая наше
      приложение. `.ipk` и манифест приложены к релизу 0.4.0.
      Осталось: прожать установку клиента кнопкой в приложении (проверка руками
      с пульта) и отправить PR в `webosbrew/apps-repo`.
- [ ] **Манифест для webosbrew** (`webosbrew-gen-manifest`) и PR в их
      репозиторий — только после проверки на живом телевизоре.
- [ ] **Текст анонса**: технический пост (как устроена маршрутизация на ядре
      без `ip rule`, чем плох mihomo, как устроен автофейловер) + короткий
      пост-объявление. Площадки по возрастанию риска: webosbrew → 4PDA
      (ветка LG) → Habr. Англоязычно — сообщества webOS.
- [ ] **Картинки для репозитория**: демо-гифка анимаций панели, схема
      «телевизор → ядро → туннель», бейджи (CI, версия, лицензия).

### Формулировки (важно)

Проект — **клиент для своей подписки**, а не «средство обхода блокировок».
Рекламировать обход нельзя: в России это административная ответственность,
и она ложится на владельца репозитория. В README и в постах держим одну
формулировку: «VPN-клиент для своего сервера на рутованном телевизоре LG».
