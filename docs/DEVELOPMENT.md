# Разработка

## Из чего состоит проект

| Файл | Роль |
|---|---|
| `src/tunnelctl.sh` | «мозг» на shell: маршруты, DNS, подъём/опускание туннеля, сторож, аварийный сброс |
| `src/genconfig.py` | превращает подписку Clash/Mihomo в конфиг sing-box (без внешних зависимостей) |
| `src/yamlite.py` | крошечный YAML-парсер для подписок |
| `src/tvtunnd.js` | демон: раздаёт панель, JSON-API, следит за автопереключением и обновлением подписки |
| `src/ui.html` | панель: один файл, без сборки, без внешних ресурсов, иконка вшита в base64 |
| `hooks/60-tvtunnel` | автозапуск клиента при загрузке телевизора |
| `hooks/55-ca-extra` | докладывает недостающие корневые сертификаты в системное хранилище |
| `tools/ca-add-links.sh` | вспомогательный скрипт для хеш-ссылок сертификатов |
| `install.sh` | установка, обновление, удаление |

Ограничения площадки, которые важно помнить:

- **Node v0.12** на телевизорах webOS 4: только ES5 (`var`, без стрелок,
  `let`, шаблонных строк, `Object.assign`), классические `http`/`fs`.
- **Chromium 68** в браузере телевизора: нет `color-mix`, `:has`, новых
  медиазапросов; `backdrop-filter` может не работать — оформление строится так,
  чтобы деградировать без потерь.
- **Нет policy routing** (`ip rule` не работает): маршрут по умолчанию ведёт в
  `sbtun` с `metric 0`, физический интерфейс держит резерв с `metric 100`.
- **Слабый процессор и 843 МБ памяти**: любые массовые операции — порциями.

## Как добавить язык

1. В `src/ui.html` найдите объект `I18N` и добавьте блок по образцу
   существующих (все ключи обязательны — недостающие подставятся из русского).
2. Добавьте код в массив `SUPPORTED`, в `LOCALES` (локаль для дат) и в
   `LANGNAMES` (как язык называется сам на себе).
3. Добавьте кнопку в блок `#langList` с `data-lang="<код>"`.
4. Проверьте: `?demo=1` в адресе панели показывает демо-данные без телевизора —
   удобно открыть файл локально в браузере.

## Как менять дизайн

Панель — чёрно-белая: цвета живут в двух блоках `:root[data-theme="light"]` и
`:root[data-theme="dark"]` (переменные `--bg --panel --ink --line --sep --ok
--bad`). Акцентных цветов нет специально: выделение делается инверсией
(чёрный фон при светлой теме, белый — при тёмной). Тема по умолчанию берётся из
`prefers-color-scheme` телевизора; выбор пользователя хранится в
`localStorage:nyamiko.theme`.

Правила: тонкие рамки 1 px, капс-подписи с `letter-spacing`, разделители вместо
карточек, анимации 140–550 мс, обязательный блок
`@media (prefers-reduced-motion: reduce)`. Подробности — [UI.md](UI.md).

## Тестирование без телевизора

```sh
python3 -m http.server 8123         # из корня репозитория
# затем в браузере:
#   http://127.0.0.1:8123/src/ui.html?demo=1
```

`?demo=1` подменяет API демо-данными: панель рисует шесть узлов, задержки,
подключённое состояние. Так можно проверить вёрстку, языки, тему и управление с
клавиатуры (стрелки = пульт, Enter = OK, Esc = BACK).

Проверки перед коммитом:

```sh
sh -n install.sh && sh -n src/tunnelctl.sh && sh -n hooks/*
node --check src/tvtunnd.js
python3 -m py_compile src/genconfig.py src/yamlite.py
grep -rInE 'https?://[^ "]+/sub/[A-Za-z0-9_-]{16,}' .   # должно быть пусто
```

То же самое делает CI в `.github/workflows/ci.yml`.

## Как проверить на живом телевизоре

```sh
sh install.sh --update                  # обновить файлы, ключи останутся
sh /media/internal/tv-tunnel/tunnelctl.sh status
curl -s 127.0.0.1:8099/api/status
curl -s -o /dev/null -w '%{http_code}\n' https://www.youtube.com/
```

Порядок приёмки выпуска — [PUBLISH.md](PUBLISH.md).

## Стиль коммитов

Короткое сообщение в императиве, по-английски или по-русски, но одинаково во
всём репозитории: `panel: pick up the system language on first run`. Один
коммит — одно изменение. Всё, что меняет поведение туннеля, проверяется на
живом телевизоре и попадает в CHANGELOG.
